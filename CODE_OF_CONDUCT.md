# Code of conduct

This project welcomes constructive participation from people of all backgrounds and experience levels.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and changes rather than people.
- Assume good intent while remaining clear about technical and safety concerns.
- Respect privacy and do not publish another person's confidential information.
- Accept maintainer decisions about repository scope and moderation.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, deliberate disruption, and publication of private information are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove contributions, comments, issues, or other participation that violates this policy. Repeated or serious violations may result in a temporary or permanent ban from project spaces.

Use GitHub's private reporting and abuse tools when a public report would expose a person to further harm. Security vulnerabilities must be reported through the private process described in [SECURITY.md](SECURITY.md).

This policy applies in repository discussions and in public spaces where someone is representing this project.
